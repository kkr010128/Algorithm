# 문자열 내 문자 수정

## 출처

[https://www.codetree.ai/ko/trails/complete/curated-cards/intro-filling-with-a/introduction](https://www.codetree.ai/ko/trails/complete/curated-cards/intro-filling-with-a/introduction)

## 학습 목표

`문자열 내 문자 수정`을 사용할 상황과 실행 순서를 구분해 정리한다. 문자열은 문자들의 순서 있는 모음이다. 길이와 인덱스 범위를 확인하고 필요한 구간 또는 문자를 선택한다.

## 직접 만든 예제

```java
String text = "abc";
for (int i = 0; i < text.length(); i++) System.out.println(text.charAt(i));
```

## 점검 항목

- 입력과 출력의 자료형을 확인한다.
- 경계값에서 같은 규칙이 적용되는지 확인한다.
- 실행 순서를 손으로 한 번 추적한다.
