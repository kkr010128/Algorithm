# 2차원 배열에서의 변수 사용

## 학습 목표

`2차원 배열에서의 변수 사용`을 사용할 상황과 실행 순서를 구분해 정리한다. 배열은 같은 종류의 값을 인덱스로 관리한다. 순회 범위와 인덱스의 시작·끝을 먼저 정한 뒤 값을 읽거나 갱신한다.

## 직접 만든 예제

```java
int[] values = {1, 2, 3};
for (int value : values) System.out.println(value);
```

- 경계값에서 같은 규칙이 적용되는지 확인한다.
- 실행 순서를 손으로 한 번 추적한다.
