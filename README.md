알고리즘 개념과 문제 풀이를 `분류 → 플랫폼 → 문제` 순서로 관리한다. 난이도와 보조 분류는 각 README의 YAML 메타데이터에 기록한다.

## 문제 문서 규칙

- 식별자는 `platform + platform_problem_id` 조합으로 관리한다.
- 한 문제는 하나의 대표 분류 디렉터리에만 둔다.
- 추가 분류는 `tags`에 기록한다.
- 난이도는 플랫폼 표기를 보존하되 디렉터리명에는 넣지 않는다.
- CodeTree 문서는 원본 링크, 자체 요약, 입출력 예시, 풀이 접근, 복잡도, 본인 코드만 둔다.
- CodeTree 원문 설명, 해설, 이미지와 교육 자료 본문은 복제하지 않는다.

## 새 문제 추가

1. 대표 알고리즘 분류를 선택한다.
2. 해당 분류 아래 플랫폼 디렉터리를 선택한다.
3. 플랫폼 문제 번호와 제목으로 디렉터리를 만든다.
4. 공통 YAML 메타데이터와 원본 링크를 작성한다.
5. 풀이 코드와 직접 작성한 접근법을 추가한다.

자동 업로드 및 외부 서비스 동기화는 사용하지 않는다.
