## 학습 목표

`재귀 트리`을 사용할 상황과 실행 순서를 구분해 정리한다. 재귀 함수는 더 작은 입력에 대한 같은 문제로 작업을 줄인다. 종료 조건과 호출 뒤에 수행될 연산을 분리해 추적한다.

## 직접 만든 예제

```java
static int sum(int n) {
    if (n == 0) return 0;
    return n + sum(n - 1);
}
```

## 점검 항목

- 입력과 출력의 자료형을 확인한다.
- 경계값에서 같은 규칙이 적용되는지 확인한다.
- 실행 순서를 손으로 한 번 추적한다.
